# decide

Read the workspace and review first. Record only the assigned reviewer’s actual decision and evidence. Holds block archive recommendations.

Run:

```bash
npm run gov -- decide --tenant=DEMO --review=REVIEW-ID --decision=retain --evidence="Source reference" --actor="Reviewer"
```

Replace example values with operator-provided values. Add --json for machine output. If a reference is ambiguous, show the candidates and ask which one. Never send, change permissions, archive a Microsoft workspace or claim compliance from these records.
