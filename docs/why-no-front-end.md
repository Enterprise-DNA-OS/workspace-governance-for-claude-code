# A review desk without another application

Ownership, activity dates, sharing settings, reviews and evidence fit a database. Ask for the weekly review, record a decision and render the pack. Read-only HTML provides a view of the result without a web server or another application to maintain.

A live screen adds mobile entry, continuous scanning, authenticated end-user reviews, permission browsing and immediate remediation. This base supplies none of those. It does not edit Microsoft 365 or replace its administrator controls. Evidence comes from exports and operator-recorded verification.

Enterprise DNA builds the agreed connections, authentication and screens into your version. The free system keeps the review process useful offline. Claude Code, Codex, OpenCode and Cursor all follow the same command recipes. No separate version per agent.
